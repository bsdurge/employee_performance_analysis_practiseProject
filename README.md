# Employee Performance Analysis | Excel

## Project Overview
This beginner-friendly data analytics project uses Microsoft Excel to analyze employee performance across departments and regions. An interactive dashboard summarizes sales, targets, orders, customer ratings, and attendance to make performance monitoring easier.

## Business Problem
Organizations need a consolidated view of employee performance to understand sales target achievement, compare departments and regions, and identify areas that may require further investigation.

## Project Objectives
- Compare actual sales against sales targets.
- Analyze sales performance across departments and regions.
- Monitor total orders and average customer ratings.
- Examine employee attendance across departments.
- Present key performance indicators through an interactive dashboard.

## Tools & Skills
- **Microsoft Excel**
- Data cleaning and preparation
- PivotTables and PivotCharts
- KPI cards
- Slicers and interactive filtering
- Excel formulas and percentage formatting
- Dashboard design and data visualization

## Dashboard Features
- Total Sales
- Total Target
- Target Achievement %
- Total Orders
- Average Customer Rating
- Sales by Department
- Sales by Region
- Average Attendance by Department
- Interactive slicers for exploring the data

## Data Preparation
The dataset was reviewed and prepared for analysis by checking for duplicate records, missing values, extra spaces, and appropriate data types.

## Business Value
The dashboard brings important employee performance metrics into one view, helping users compare performance across departments and regions, monitor target achievement, and identify areas for further analysis.

## Learning Outcomes
- Practiced cleaning and organizing data in Excel.
- Learned to summarize data using PivotTables.
- Built an interactive dashboard using PivotCharts and slicers.
- Presented performance metrics using KPI cards.
- Practiced translating business questions into measurable indicators.

## Project Type
Beginner Practice Project

**Note:** This is a practice project created for learning purposes. The dashboard supports performance analysis but does not establish the causes of differences in sales or attendance.
